# D28 — กล่องยอดสมทบ ปุ่มการ์ด และเสียงลูบสัตว์

วันที่ 12 ต.ค. 2026 ต่อจาก D27 ดูกติกาหลักใน PROMPT.md/MOTION.md/STORYBOARD.md D28 และแหล่งเสียงใน CREDITS.md

## ดูตรงไหน

- หน้าแรกหรือ `/dashboard#micro-donations`: กล่องยอดสมทบและสามยอดย่อยใช้ `PetFrame`/`PetStat` ชุดเดียวกับ `/profile#profile-credit` กรอบขาวครีมมน อุ้งเท้าตามสวิตช์ส่วนกลาง แมวสี butter หมา peach
- `/dashboard#crisis-cases` และเคสเร่งด่วนบนหน้าแรก: ปุ่มท้ายการ์ดอยู่ระดับเดียวกันภายในแถว แม้บางแห่งไม่มีข้อมูลทรายแมวหรือชื่อมีหลายบรรทัด ไม่เติมข้อมูลเสบียงขึ้นเอง
- `/partners?tab=csr`: ใช้พื้นที่ action ท้ายการ์ดเดียวกัน รูปเต็มกรอบ 16:9
- หน้าแรก: เปิดปุ่ม `เสียง: เปิด` ที่แถบล่าง แล้วแตะ/คลิกน้องที่เกาะโต๊ะหรือสัตว์ในฉากก่อนซูมเข้าปาก → หน้าฟิน 1 วินาที หัวใจเหนือหัว และคลิปเสียงจริงตามสัตว์

## กติกาเสียง

- เริ่ม mute ไม่เล่นหรือ preload ตอนเข้าเว็บ แม้เคยบันทึก Sound on ไว้ การเปิดเสียง/เลือกสัตว์ขณะเปิดเสียงเป็น gesture สำหรับเตรียมคลิป การกดสัตว์เป็น gesture สำหรับเล่น
- คลิป CC0 จาก Joseph SARDIN / BigSoundBank: `cat-purr.wav` 1.35 วินาที และ `dog-pant.wav` 1.25 วินาที เป็น mono 22050 Hz / PCM16 รวม 114750 bytes แมวครางและหมาหายใจ/หอบ ไม่ถือเป็นการยืนยันอารมณ์ของสัตว์ในไฟล์ต้นฉบับ
- โหลดจาก `/audio/` ของเว็บ ไม่ใช้ hotlink หรือ API บันทึก buffer cache และ fade หัวท้าย เสียงล้มเหลวไม่ทำให้ปฏิกิริยาและหัวใจล้มเหลว
- ปิดเสียงหยุด source และลด master gain สลับสัตว์/ออกจากหน้า invalidate การเล่นค้าง กดรัวไม่เล่นซ้อน หากโหลดช้าเกินหน้าฟินหรือผู้ใช้ปิดเสียงไปแล้วจะไม่เล่นคำตอบเสียงที่มาช้า
- ไม่มีเพลงเพิ่ม ไม่มีค่าใช้จ่าย บัญชีใหม่ หรือ dependency เพิ่ม ค่าเสียงไม่เปลี่ยนข้อมูล Run ยอดสมทบ หรือข้อมูลสัตว์
