# เปิดดูหัวข้อที่เพื่อนส่งใน Cozypet รุ่น D26

เว็บ: https://cozypet-iota.vercel.app/ · ทุกยอด/การซื้อ/องค์กรธุรกิจ/การส่งของเป็นการจำลอง ใช้ browser เดียวกันเพื่อให้ประวัติต่อเนื่อง

ก่อนเริ่ม: กด “เริ่มช่วยน้อง/ทดลอง Demo” เลือก Run 001–100 ใช้ Run เดิมตลอดการสาธิต ไม่ต้องตั้ง API key และไม่ต้องกรอกบัตรหรือโอนเงิน

## 1. หน้าแรก / Dashboard

- **Micro-Donation Tracker:** เปิด `/#micro-donations` หรือ `/dashboard#micro-donations` หัวข้อ “น้ำใจเล็ก ๆ รวมเป็นมื้อใหญ่” เลือกมูลนิธิสมมติ ติ๊กเข้าใจเดโมแล้วกดสมทบ 50/100 ยอดรวม จำนวนครั้ง ยอดรอ และแพ็กเกจถัดไปเปลี่ยนทันที
- ตัวอย่างบ้านอุ่นใจ: 50+100+100+100 = 350 บาท ครบแพ็กเกจอาหารหมา ระบบสร้างออเดอร์ `pool-foundation-demo-001-0001` พร้อมลิงก์ดูการส่ง ยอดเศษเก็บไว้ให้เคสเดิม ไม่หักเก็บเป็นรายได้โดยยังไม่ได้สั่งสินค้า
- **Crisis Alert:** `/#crisis-cases` หรือ `/dashboard#crisis-cases` หัวข้อ “เคสที่รอความช่วยเหลือก่อน” มีภาพ ชื่อ อาหารเหลือ และความจุจริงจาก record สาธิต ส่งอาหารถึงแล้วสถานะอาหาร/ลำดับแนะนำเปลี่ยนได้ การให้อาหารไม่เพิ่มพื้นที่ว่างเอง
- **Ad Banners:** `/#sponsor-home` หรือ `/dashboard#sponsor-dashboard` แบนเนอร์ชื่อแบรนด์สมมติ มีปุ่มแพ็กเกจและ “แบรนด์และผู้สนับสนุน” ก่อนจองแสดงเป็นตัวอย่างพื้นที่ เมื่อจองใน `/partners` แล้วกลับมาหน้าเดิมจะเห็นแบรนด์ที่เลือกตามบริบทแมว/หมา
- **ยอดเรียลไทม์ในขอบเขตเดโม:** อัปเดตจากกิจกรรมใน browser/แท็บเดียวกัน ไม่ใช่ยอดเงินจริงทั่วประเทศหรือการรวมจากหลายเครื่อง

## 2. หน้าค้นหา / แผนที่

- กด “ค้นหา” ที่แถบล่าง หรือเปิด `/nearby`
- ในตัวเลือกค้นหา พิมพ์ “ดินแดง” หรือ “Din Daeng” ในช่อง “พิมพ์เขตที่ต้องการค้นหา” กดชื่อที่แนะนำหรือ “ค้นหาเขต” จะย้ายจุดค้นหาตัวอย่างไปเขตนั้น มี radar แล้วแสดงหมุด/รายการ
- ใช้ “ประเภท” เลือกสถานสงเคราะห์หรือผู้ดูแลรายบุคคล พร้อมชนิดสัตว์ ระยะ ความพร้อม ความเร่งด่วนและเรียงลำดับ
- เขียว = รับได้, สีส้ม = ใกล้เต็ม, แดง = เต็ม ป้ายอาหารขาดแคลนแสดงแยกจากความจุ ไม่มีการรับรองว่าองค์กรจดทะเบียนจริงจากสีหรือดาว
- จังหวัดอื่น เช่น ลพบุรี ไม่ใช่พื้นที่ทดลอง แจ้งว่ารองรับ 50 เขตของกรุงเทพฯ แทนการแต่งหมุดใหม่

## 3. Smart Redirection Pop-up

- ลอง `/nearby?species=dog&district=bang-kapi&auto=1`
- คลิกหมุดสีแดงของ **มูลนิธิเพื่อนสี่ขา (สมมติ)** ซึ่งดูแล 40/40 ตัว
- pop-up แสดงว่าเต็ม พร้อมสถานที่อื่นที่ยังมีพื้นที่ว่าง เหตุผลและระยะจากจุดค้นหาตัวอย่าง กด “ดูบนแผนที่” หรือเปิดรายละเอียดต่อได้
- คำนวณด้วย Smart Load Balancer เดียวกับผลค้นหา AI ช่วยอธิบายเมื่อเปิดใช้ provider แต่ไม่เป็นผู้แต่งตัวเลือกหรือระยะทางเอง

## 4. รายละเอียดมูลนิธิ / ผู้ดูแล

เปิด `/helpers/foundation-demo-001` (บ้านอุ่นใจ) หรือกดรายละเอียดจากเคสหน้าแรก/แผนที่

### แพ็กเกจ + Commission / Dropship

1. เลือกแพ็กเกจ หรือ “ส่งแพ็กเกจของใช้” → `/donate?helper=foundation-demo-001`
2. เลือกแพ็กเกจ เช่นอาหารแมว 290 บาท จำนวน 1 กดถัดไป
3. ตรวจผู้รับ/ยอด/ส่วนแบ่ง ติ๊กเข้าใจคำสั่งจำลอง กด “ยืนยันคำสั่งจำลอง”
4. หน้าออเดอร์แสดงเงินเข้า 290 กด “จำลองการหักส่วนแบ่ง” → รายได้เว็บ 29 บาท ต้นทุน 261 บาทรอส่งต่อ
5. กด “จำลองส่งออเดอร์และโอนต้นทุนให้คู่ค้า” → เริ่ม timeline ส่งตรงจากคู่ค้าถึงมูลนิธิ ไม่มีสต็อกของเว็บ
6. กด “เร่งเวลา (จำลอง)” ให้เห็นถึงผู้ดูแลและข้อความขอบคุณได้ทันที ออเดอร์กองอาหารเดินเวลาจำลองเอง
7. `/dashboard#platform-revenue` แยกเงินช่วยเหลือออกจากรายได้ Commission, โฆษณา, ค่าโปรโมต CSR และเงินรอส่งต่อ

### Transparency Tracker

1. กลับหน้ามูลนิธิ หัวข้อ “กระดานความโปร่งใส”
2. ต้องมีออเดอร์ของ Run นี้ที่ส่งถึงแล้วก่อน
3. เลือกออเดอร์ อัปโหลด JPG/PNG/WebP ไม่เกิน 5 MB ใส่ข้อความอย่างน้อย 3 ตัวอักษร กดบันทึก
4. รูปขึ้นอัลบั้มพร้อมข้อความ/รหัสออเดอร์/เวลา เป็นบทบาทผู้ดูแลจำลอง ไม่ใช่หลักฐานการบริจาคจริง ภาพถูกเก็บใน browser ไม่มีการอัปโหลดขึ้นบริการภายนอก

### Review & Rating

1. หัวข้อ “ดาวและรีวิวจากกิจกรรมทดลอง”
2. ต้องมีออเดอร์ถึงแล้วหรือผลส่งต่อที่ยืนยันใน Run นี้
3. เลือก 1–5 ดาว ใส่ข้อความ 5–500 ตัวอักษร กดบันทึก/แก้ไข
4. เห็นรีวิวของ Run ค่าเฉลี่ย และจำนวนรีวิว หนึ่งรีวิวต่อที่/Run ดาวไม่ใช่การยืนยันว่ามีสถานที่จริงหรือปลอดภัย

### Agreement Download

- กด “พิมพ์ / ดาวน์โหลดสัญญาตัวอย่าง” → `/agreements/adoption?helper=foundation-demo-001`
- กด “พิมพ์ / บันทึกเป็น PDF” แล้วเลือก Save as PDF หรือเครื่องพิมพ์ใน browser
- ถ้ามีคำขอรับเลี้ยง/อุปถัมภ์ เปิดหน้าคำขอ → เทมเพลตสัญญา (`/requests/[id]/agreement`) เติมข้อมูลจากคำขอของตัวเอง สถานะ pending ไม่ถือว่ารับเลี้ยงสำเร็จ
- มีลายน้ำตัวอย่าง ไม่มีลายเซ็นดิจิทัล ไม่มีเลขบัตรหรือที่อยู่จริง และไม่ออกเอกสารแทนองค์กรจริง

## 5. บัญชีส่วนตัว / User Credit

- กด “โปรไฟล์” ที่แถบล่าง หรือเปิด `/profile`
- เห็นยอดช่วยเหลือ/จำนวนครั้งของ Run ปัจจุบัน (แพ็กเกจที่ยัง active + เงินที่ตัวเองสมทบ) ประวัติแพ็กเกจและกองอาหาร
- จำนวนรับเลี้ยงนับเฉพาะผลส่งต่อที่ยืนยันชนิด adopt ส่วนอุปถัมภ์/ส่งต่อแยกกัน คำขอรอการติดต่อไม่ถูกนับว่ารับเลี้ยงแล้ว
- แต้มน้ำใจรวมกิจกรรมจริงในเดโม ใช้เพดานรายวันเดิม ไม่ให้แต้มซ้ำจากออเดอร์กองกลาง และไม่มีมูลค่า/การรับรองบุคคลจริง
- `/profile#reset` รีเซ็ตข้อมูลทดลองหลังยืนยัน รวมข้อมูลธุรกิจใหม่ด้วย เก็บ Run/สัตว์/ภาษาเดิม

## รายได้โฆษณาและ CSR

- `/partners`: เลือกแบรนด์สมมติ แพ็กเกจ Home/Dashboard ระยะเวลา กลุ่มสัตว์ ดู preview ติ๊กเข้าใจเดโมแล้วจอง
- กลับหน้า Home/Dashboard ดูป้ายแบรนด์นั้น และ `/dashboard#platform-revenue` ดูค่าโฆษณาที่เพิ่ม
- `/partners?tab=csr`: เลือกแบรนด์ ติ๊กเข้าใจเดโม เลือกหนึ่งแคมเปญ กดสนับสนุนแบบเหมาจ่าย
- ค่าอาหารทั้งหมดส่งให้คู่ค้า รายได้เว็บเป็นค่าโปรโมตแยก ไม่มี commission ซ้ำจากงบอาหาร มีชื่อสปอนเซอร์และลิงก์ออเดอร์ ความคืบหน้านับเมื่อแพ็กเกจส่งถึง
- ยกเลิกได้ใน “รายการของคุณ” ทำให้แบนเนอร์/ผลของรายการ/รายได้จำลองปรับตาม
