# Cozypet

**ทุกการพบเจอ อาจพาน้องกลับบ้าน** — เว็บต้นแบบ (Final Project prototype ของ **ทีมก้าวหน้า**) ที่ช่วยคนพบสัตว์หลง เจ้าของที่กำลังตามหา สถานสงเคราะห์ ผู้รับดูแล ผู้บริจาค และผู้ที่อยากอุปถัมภ์หรือรับเลี้ยง ให้ความช่วยเหลือไปถึงที่ที่ยังรับได้และต้องการที่สุด ด้วย **Smart Load Balancer** ในกรุงเทพฯ

## Cozypet คืออะไร

เมื่อพบสัตว์หลง คำถามแรกควรเป็น **“น้องมีเจ้าของกำลังตามหาอยู่ไหม”** Cozypet พาผู้ใช้ไปตามลำดับนี้:

1. **สแกนสัตว์ที่พบ** — ถ่าย/เลือกรูป กรอกจุดสังเกต แล้วเทียบกับประกาศสัตว์หายตัวอย่าง
2. **ถ้าพบประกาศที่อาจตรง** — ดูเหตุผลที่อาจตรงและคุยกับเจ้าของ (persona สมมติผ่านผู้ช่วย AI)
3. **ถ้ายังไม่พบในข้อมูลตัวอย่าง** — ลงประกาศพบสัตว์ แล้วค้นหาสถานสงเคราะห์หรือผู้รับดูแลใกล้จุดค้นหาตัวอย่าง คุยกัน และยืนยันส่งต่อน้อง (จำลอง)
4. **อุปถัมภ์หรือรับเลี้ยง** — สำหรับน้องในประกาศ “หาบ้าน” โดยแยกการดูแลชั่วคราวกับการรับเลี้ยงถาวรให้ชัด
5. **Smart Load Balancer** — เมื่อที่ใกล้สุดเต็ม ระบบแนะนำที่ที่ยังรับได้พร้อมเหตุผล (เปิดดู “เบื้องหลัง” ได้) และ AI ช่วยสรุปสถานการณ์จากข้อความที่ผู้ใช้เล่า
6. **แพ็กเกจของใช้ (จำลอง)** — ส่งของจากแบรนด์พันธมิตรสมมติไปยังผู้รับดูแลที่ขาดแคลนที่สุด ติดตามได้ทุกขั้น โดยไม่มีการเก็บเงินจริง

หลักสำคัญ: การยังไม่พบประกาศ **ไม่ได้แปลว่าน้องไม่มีเจ้าของ** การส่งคำขอ **ไม่ใช่การอนุมัติ** และทุกคำแนะนำต้อง **อธิบายเหตุผลได้**

ปัญหาที่ตอบโจทย์ Final Project: **ทรัพยากรช่วยเหลือสัตว์กระจายไม่สมดุล** (รายละเอียดใน [PROMPT.md หัวข้อ 1.1](PROMPT.md#11-ปัญหาและเป้าหมาย) และงานส่งทั้งหมดใน [SUBMISSION.md](SUBMISSION.md))

| คำขอส่งน้อง/อุปถัมภ์/รับเลี้ยง | บันทึกในเบราว์เซอร์ สถานะ “รอการติดต่อ (demo)” เท่านั้น |

| แชต | ผู้ช่วย AI จาก provider ฟรี (Gemini / Groq / OpenRouter) ตอบในบท persona สมมติ หรือบทสนทนาตัวอย่างเมื่อไม่ได้เปิด AI |
| สถานะสี เสบียง และความเคลื่อนไหวล่าสุด | คำนวณจากข้อมูลตัวอย่าง ไม่ใช่สถานะเรียลไทม์จริง |

| แพ็กเกจของใช้ แบรนด์ ราคา และยอดรวม | คำสั่งจำลอง แบรนด์สมมติ ราคาตัวอย่าง ยอดจำลอง ไม่มีการชำระเงินหรือจัดส่งจริง |
| แต้มน้ำใจ | คำนวณจากกิจกรรมในแอป ไม่มีมูลค่า |
| หน้าจำลองสถานการณ์ | การจำลองด้วยสถานที่สมมติ ไม่ใช่ผลจริง |

**บัญชีผู้ใช้เป็นของจริง** (Google หรืออีเมล/รหัสผ่านผ่าน Supabase) ใช้เก็บข้อมูลทดลองข้ามเครื่อง แต่ไม่ใช่การยืนยันตัวตน ส่วนปุ่ม **“ทดลอง Demo”** ใช้ได้ครบทุก flow โดยไม่ต้องสมัคร และเก็บข้อมูลใน localStorage ของเบราว์เซอร์นั้นเท่านั้น

## ฟีเจอร์ที่วางแผนไว้

- Landing Page 6 section: Hero, วิธีช่วยน้อง 3 ขั้นตอน, หาที่ช่วยเหลือ, เรื่องราวน้องที่ได้บ้านแล้ว, เกี่ยวกับ Cozypet, CTA/footer
- animation เล่าเรื่อง “Cozypet ทำงานยังไง” ~1 นาที สไตล์คลิปโปรโมต (WebGL + เสียงน่ารักที่สังเคราะห์ด้วยโค้ด ปิดเสียงเป็นค่าเริ่มต้น) และเอฟเฟกต์เสริมในหน้าสแกน ค้นหา และแชต
- Mascot animation **น้องแมว** (ค่าเริ่มต้น โผล่เกาะขอบโต๊ะ) และ **น้องหมา** สลับได้จาก tab bar/dock มองตามเมาส์/นิ้ว แตะแล้วมีหัวใจลอย รองรับคีย์บอร์ดและ reduced motion
- สแกนสัตว์ที่พบ (กรณีพบประกาศที่อาจตรง / ยังไม่พบ)
- แท็บ **“ค้นหา”** → หน้า “ค้นหาความช่วยเหลือในกรุงเทพฯ” มี radar แผนที่ mockup ตัวกรอง และความจุ เช่น “ดูแลอยู่ 95/100 ตัว · รับเพิ่มได้ 5 ตัว”
- กระดานประกาศ “สัตว์หาย / พบสัตว์ / หาบ้าน” และฟอร์มลงประกาศ
- คำขอ 3 แบบ: “ขอส่งน้องเข้าดูแล”, “ขออุปถัมภ์ชั่วคราว”, “ขอรับเลี้ยงถาวร” แต่ละแบบมีฟอร์มและหน้าสถานะของตัวเอง
- โปรไฟล์ผู้รับดูแลพร้อมภาพ บ้าน น้องที่ดูแลอยู่ และความสนใจพิเศษ (สี/พันธุ์ + เหตุผล)
- แชตสวยงามแบบแอปแชต มีสถานะ “อ่านแล้ว” ตัวบอกกำลังพิมพ์ quick reply และ animation “คุณ… รับน้อง…ไปดูแลต่อแล้ว” หลังยืนยันส่งต่อน้อง (จำลอง)
- RUN_NUMBER 001–100 สำหรับผู้ทดลองแต่ละคน และปุ่มรีเซ็ตข้อมูล demo
- **เข้าสู่ระบบจริง** ด้วย Google หรืออีเมล/รหัสผ่าน และปุ่มเล็ก “ทดลอง Demo” ที่ไม่ต้องสมัคร
- **แดชบอร์ด:** เคสเร่งด่วน ยอดแพ็กเกจ (ยอดจำลอง) ภาพรวมพื้นที่ แต้มน้ำใจ และประวัติกิจกรรม
- **Smart Load Balancer:** สีสถานะบนแผนที่ (รับได้/ใกล้เต็ม/เต็ม), pop-up แนะนำที่ว่างเมื่อที่เลือกเต็ม, แผง “เบื้องหลัง”, และ “เล่าให้ AI ช่วยสรุป”
- **แพ็กเกจของใช้ (จำลอง)** พร้อม timeline ติดตาม, สถานที่ของฉัน (ทดลอง), เทมเพลตสัญญา (ตัวอย่าง) และหน้าจำลองสถานการณ์ 30 วัน
- **ภาษาไทย / English** สลับได้ทุกหน้า
- หน้าส่งออกงานส่ง (โปสเตอร์ สไลด์ รายงาน ฟอร์ม) และการ render วิดีโอเดโมด้วยโค้ด

## วิธีเล่น demo (หลัง implement)

0. **เข้าสู่ระบบหรือทดลอง:** ไปที่ “เข้าสู่ระบบ” แล้วเลือก Google / อีเมล หรือกดปุ่มเล็ก **“ทดลอง Demo”** (ไม่ต้องสมัคร)
1. เปิดเว็บ กด **“ฉันพบสัตว์”** แล้วใส่ **RUN_NUMBER** 001–100 ที่ผู้สอนแจก (หรือกด “ลองด้วยเลข 001”)
2. **สแกน:** กด “ใช้รูปตัวอย่าง” เลือกชนิด “แมว” สี “ส้ม + ขาว” ปลอกคอ “มี · สีแดง” เขต “พระโขนง” เลือก “ลองกรณีพบประกาศที่อาจตรง” แล้วเริ่มสแกน → จะพบ “มะม่วง” ของ “นารา”
3. **แชตกับเจ้าของ:** กด “คุยกับเจ้าของ (ผู้ช่วย AI)” แล้วลองถาม “คุณคือใคร” หรือ “คุณเป็น AI หรือคนจริง” ดูสถานะ “อ่านแล้ว” ใต้ข้อความ
4. **กรณีไม่พบ:** สแกนใหม่ด้วย “ลองกรณียังไม่พบประกาศ” → ลงประกาศพบสัตว์ แล้วไปแท็บ **“ค้นหา”**
5. **ค้นหาความช่วยเหลือ:** ดูจุดค้นหาตัวอย่างของ Run ลองตัวกรอง เปิดการ์ดสถานสงเคราะห์ช่อง `shelter-001` ที่ “ดูแลอยู่ 95/100 ตัว (ข้อมูลสาธิต)” และกด “เปิดรับบริจาค” เพื่อดูว่าเป็นสถานะตัวอย่าง
6. **ส่งต่อน้อง:** เปิดการ์ด “persona หลักของ Run” คุยสักรอบ แล้วกด **“ยืนยันส่งต่อน้อง (จำลอง)”** → ดู animation “คุณ… รับน้อง…ไปดูแลต่อแล้ว”
7. **อุปถัมภ์/รับเลี้ยง:** ไปหน้า “ประกาศ” แท็บ “หาบ้าน” แล้วลอง “ขออุปถัมภ์ชั่วคราว” หรือ “ขอรับเลี้ยงถาวร”
8. **สลับ mascot:** กด “น้องหมา” ที่ tab bar/dock แล้ว refresh เพื่อดูว่าจำค่าไว้
9. **รีเซ็ต:** หน้า “โปรไฟล์” → “รีเซ็ตข้อมูล demo” หรือ “เริ่มใหม่ทั้งหมด” (ที่หน้านี้เลือก “ใช้บทสนทนาตัวอย่างเสมอ” ได้ถ้าไม่ต้องการเรียก AI)
10. **Smart Load Balancer:** ในแท็บ “ค้นหา” พิมพ์เล่าสถานการณ์ใน “เล่าให้ AI ช่วยสรุป” → แตะหมุดสีแดง (เต็ม) → ดูที่แนะนำและกด “ดูเบื้องหลัง”
11. **แพ็กเกจของใช้:** แดชบอร์ด → “ส่งแพ็กเกจของใช้” → เลือกผู้รับที่ระบบแนะนำ → ยืนยันคำสั่งจำลอง → กด “เร่งเวลา (จำลอง)” เพื่อดู timeline
12. **หน้าจำลองสถานการณ์:** เปิด “Smart Load Balancer ทำงานยังไง” (`/insights`) แล้วกด “เริ่มจำลอง 30 วัน”
13. **ภาษาอังกฤษ:** กด “ภาษา: ไทย / EN” ที่ header

> ถ้าสองคนใช้ RUN_NUMBER เดียวกัน ผลจะเหมือนกันโดยตั้งใจ

## ตั้งค่า AI provider (ฟรีเท่านั้น · งบ API 0 บาท)

รองรับ **Gemini**, **Groq** และ **OpenRouter** เลือกได้ทีละเจ้า ทุกเจ้าใช้กติกา persona และประวัติแชตชุดเดียวกันจาก GEMINI_ROLEPLAY.md รายละเอียดทั้งหมดอยู่ใน [PROMPT.md หัวข้อ 12](PROMPT.md#12-แชต-ai-ผ่าน-vercel)

1. คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่าของคุณเอง **ห้าม commit ไฟล์นี้** และห้ามตั้งชื่อตัวแปรขึ้นต้นด้วย `NEXT_PUBLIC_`

   ```bash
   AI_PROVIDER=demo            # demo | gemini | groq | openrouter
   AI_MODEL=                   # model ID ที่ตรวจแล้วว่าฟรี (ไม่มีค่า default)
   GEMINI_API_KEY=
   GROQ_API_KEY=
   OPENROUTER_API_KEY=
   CHAT_RATE_LIMIT_PER_MIN=6
   CHAT_RATE_LIMIT_PER_DAY=40
   CHAT_GLOBAL_DAILY_LIMIT=300
   ```

2. สร้าง key เฉพาะเจ้าที่จะใช้:
   - **Gemini:** สร้าง API key ใน [Google AI Studio](https://aistudio.google.com/) ด้วย project ที่ **ไม่เปิด billing** (ไม่ต้องซื้อ Google AI Plus/Pro)
   - **Groq:** สร้าง key ใน [GroqCloud](https://console.groq.com/) ด้วย free plan **ไม่ผูกบัตรและไม่อัปเกรด**
   - **OpenRouter:** สร้าง key ใน [OpenRouter](https://openrouter.ai/) **ไม่เติมเครดิต** และใช้เฉพาะ model ID ที่ **ลงท้าย `:free`**
3. **เลือกรุ่นก่อนตั้งค่า:** ตรวจเอกสารทางการ ณ วันที่ตั้งค่าว่ารุ่นนั้นยังฟรี รองรับภาษาไทย และเหมาะกับแชตสั้น แล้วเติมตารางเปรียบเทียบใน [GEMINI_ROLEPLAY.md หัวข้อ 6](GEMINI_ROLEPLAY.md#6-เปรียบเทียบ-provider-ก่อนเลือกตัวหลัก) ก่อนเลือก provider หลัก
4. รัน `npm run dev` ใหม่ แชตจะแสดงป้าย “ผู้ช่วย AI” และชื่อ provider เมื่อเรียกสำเร็จ

**ด่านงบ 0 บาท (ตรวจทุกครั้งก่อนแชร์ลิงก์)**
- [ ] ไม่มีบัญชี provider ใดเปิด billing เติมเครดิต หรืออัปเกรดแพ็กเกจเสียเงิน
- [ ] `AI_MODEL` เป็นรุ่นฟรีที่ตรวจแล้ว และถ้าเป็น OpenRouter ต้องลงท้าย `:free`
- [ ] ไม่มีการ fallback อัตโนมัติไปรุ่นหรือ provider อื่น (ถ้าใช้ไม่ได้ จะเปลี่ยนเป็นบทสนทนาตัวอย่าง)
- [ ] `CHAT_GLOBAL_DAILY_LIMIT` + `ASSIST_GLOBAL_DAILY_LIMIT` ต่ำกว่าโควตาฟรีรายวันของรุ่นที่เลือก
- [ ] Supabase อยู่ใน free plan และ Google Cloud project ที่ใช้ทำ OAuth ไม่ได้เปิด billing

**ผลการเลือก provider หลัก:** _ยังไม่ได้เลือก (ใช้ `AI_PROVIDER=demo`)_ — เมื่อเลือกแล้วให้บันทึก provider, model ID และวันที่ตรวจที่นี่

Smart Assist (“เล่าให้ AI ช่วยสรุป” และคำอธิบายเหตุผล) ใช้ provider และโควตาเดียวกับแชต ตั้งเพดานเพิ่มได้ด้วย `ASSIST_RATE_LIMIT_PER_MIN=10` และ `ASSIST_GLOBAL_DAILY_LIMIT=200` (เพดานรายวันของแชต + Assist รวมกันต้องต่ำกว่าโควตาฟรี)

## ตั้งค่าบัญชีผู้ใช้ (ฟรี · ไม่ผูกบัตร)

ถ้ายังไม่ตั้งค่า เว็บยังเล่นได้ครบด้วยปุ่ม “ทดลอง Demo” และหน้า login จะบอกว่าระบบบัญชียังไม่เปิด รายละเอียดทั้งหมดอยู่ใน [PROMPT.md หัวข้อ 7.9 และ 13](PROMPT.md#79-บัญชีผู้ใช้และการเข้าสู่ระบบ-login-signup-account--d13)

1. **Supabase:** สร้างโปรเจกต์ฟรีที่ [supabase.com](https://supabase.com/) (ไม่ผูกบัตร) → รัน SQL ใน `supabase/migrations/` (มีหลัง implement) → คัดลอก Project URL และ publishable/anon key
2. **Google OAuth:** ใน [Google Cloud Console](https://console.cloud.google.com/) สร้าง OAuth client แบบ Web application (ไม่ต้องเปิด billing) ใส่ redirect URI ตามที่หน้า Auth → Providers → Google ของ Supabase บอก แล้วนำ Client ID/Secret ไปใส่ใน Supabase (ไม่ใช่ใน repo) ขอ scope เฉพาะ `openid`, `email`, `profile`
3. ใน Supabase ตั้ง Site URL และ Redirect URLs เป็นโดเมนบน Vercel และ `http://localhost:3000`
4. ใส่ใน `.env.local` และ Vercel (ฝั่ง server เท่านั้น ห้ามขึ้นต้นด้วย `NEXT_PUBLIC_`):

   ```bash
   SUPABASE_URL=
   SUPABASE_PUBLISHABLE_KEY=
   SITE_URL=http://localhost:3000
   AUTH_PASSWORD_RESET_ENABLED=false
   ```

5. **ห้ามใช้ service role / secret key** ของ Supabase ในเว็บนี้
6. การยืนยันอีเมลและลืมรหัสผ่านปิดไว้ก่อน จนกว่าจะตั้ง SMTP ฟรีของตัวเอง
7. โปรเจกต์ฟรีของ Supabase อาจถูกหยุดชั่วคราวเมื่อไม่ได้ใช้ระยะหนึ่ง ให้เปิด dashboard ก่อนวันนำเสนอ

## Deploy บน Vercel (หลัง implement)

1. import repo นี้เข้า Vercel
2. Project Settings → Environment Variables → ตั้งตัวแปรตามหัวข้อด้านบน แล้ว redeploy
3. เว็บจะเปิดให้เพื่อนในห้องและผู้ชมทดลองผ่านลิงก์ **โควตา AI เป็นของบัญชี/project ที่เว็บใช้ร่วมกันทุกคน ไม่ได้แยกให้ผู้ทดลองแต่ละคน** เมื่อโควตาหมดหรือถูกจำกัดอัตรา แชตจะเปลี่ยนเป็นบทสนทนาตัวอย่างพร้อมแจ้งสถานะ

## ข้อจำกัด

- สแกนภาพ จับคู่ ตำแหน่ง ระยะทาง Verified การบริจาค แพ็กเกจของใช้ สถานะความจุ/เสบียง คำขอ และการส่งต่อน้องในแชตเป็นการจำลองทั้งหมด
- รองรับเฉพาะ 50 เขตของกรุงเทพฯ (พื้นที่อื่นอยู่ในแผนเท่านั้น)
- โหมดทดลองเก็บข้อมูลในเบราว์เซอร์เครื่องเดียว หายเมื่อล้างข้อมูลเว็บ ส่วนบัญชีผู้ใช้ซิงก์ข้ามเครื่องได้ แต่รูปในประกาศยังอยู่ในเครื่องที่ลงประกาศ
- ข้อความยาวของ persona ประกาศ และเรื่องราวอาจยังเป็นภาษาไทยในโหมด EN (มีป้ายบอก)
- โควตา AI ฟรีใช้ร่วมกันทุกคน อาจหมดระหว่างวัน เมื่อหมดแชตจะใช้บทสนทนาตัวอย่าง
- แชต AI อาจตอบไม่ตรงบ้าง จึงมีกติกา ชุดทดสอบ และป้ายบอกทุกข้อความว่าไม่ใช่คนจริง
- ภาพคนของผู้รับดูแลรายบุคคลเป็นภาพสร้างด้วย AI ไม่ใช่บุคคลจริง ส่วนสถานสงเคราะห์เป็นองค์กรจริงแต่ตัวเลขและสถานะในเดโมเป็นข้อมูลสาธิต
- รองรับ RUN_NUMBER 001–100 ถ้าต้องการมากกว่านี้ต้องเพิ่ม records

## ความเป็นส่วนตัวและความปลอดภัย

- อย่ากรอกเบอร์โทร ที่อยู่ หรือข้อมูลส่วนตัวจริงใน demo
- เมื่อเปิดใช้ AI ข้อความแชตจะถูกส่งไปยังผู้ให้บริการ AI ภายนอก บริการฟรีบางเจ้าอาจเก็บหรือใช้ข้อมูลตามนโยบายของเจ้านั้น
- รูปที่ผู้ทดลองเลือกอยู่ในเบราว์เซอร์ ไม่ถูกอัปโหลดหรือส่งให้ AI

- ไม่มี QR เลขบัญชี พร้อมเพย์ หรือช่องทางชำระเงินใด ๆ คำสั่งแพ็กเกจเป็นคำสั่งจำลองที่หยุดก่อนขั้นชำระเงิน
